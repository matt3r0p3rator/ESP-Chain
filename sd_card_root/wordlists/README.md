# Impostor Game Wordlists

This directory contains wordlist files for the Impostor game.

## How to Use

1. Copy this entire `wordlists` folder to the root of your SD card
2. The game will automatically detect all `.txt` files in this folder
3. Each wordlist should contain one word per line

## Wordlists Included

- **fruits.txt** - Common fruits
- **animals.txt** - Various animals
- **colors.txt** - Color names
- **cities.txt** - Major world cities
- **sports.txt** - Popular sports

## Creating Your Own Wordlists

Create a new `.txt` file with one word per line:

```
word1
word2
word3
```

Keep words simple and recognizable. Best results with 15-30 words per list.

## Tips for Good Wordlists

- Use words that are easy to describe with one-word clues
- Keep words within the same category
- Avoid words that are too similar (e.g., "car" and "automobile")
- Test with your group to ensure everyone knows the words
